¿Qué es una Skill?

Definición Arquitectónica

Una Skill es una capacidad modular que se puede incorporar a un agente para ampliar sus funcionalidades. Permite integrar herramientas de ejecución autónoma como navegación web, análisis de documentos, gestión de calendarios y procesamiento de datos.
